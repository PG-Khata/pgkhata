## Bug Fixes

1. **Pointer-events blocking clicks** — Added `pointer-events-none` to gradient overlays on properties, tenants, structure, dashboard pages
2. **Bills API response format** — Changed from nested `{ bill: {...} }` to flat `{ id, status, ... }` matching tenants/bookings pattern
3. **formatDateShort crash** — Added `isNaN` check for invalid dates, returns "-" instead of throwing
4. **Bookings API response format** — Added `...row.booking` spread to flatten response
5. **Generate bills month format** — Verified `padStart(2, "0")` produces correct YYYY-MM format
