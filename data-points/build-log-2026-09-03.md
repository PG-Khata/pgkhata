# PGKhata V1 — Build Log (2026-09-03)

## Scope

This release completes the meter-reading billing workflow, invoice clarity, property navigation, and repository cleanup requested during the September 3 session.

## Electricity and Billing

- Meter billing uses a reading pair per room: an opening reading and the next closing reading.
- The billed units are `closing reading - opening reading`; the first reading only establishes the baseline and bills zero units.
- The closing reading date determines the billable period, so a bill generated late still uses the actual meter-reading dates.
- A tenant who joins during that period receives a day-based share of the room electricity cost for the days they stayed.
- Bills store electricity line-item metadata: room meter units and the configured per-unit rate. The invoice renders these as, for example, `352 units` and `₹12/unit`.
- New invoices are due five calendar days after their issue timestamp. A bill issued on 3 September is due on 8 September.
- Existing invoices are snapshots: delete and regenerate an old invoice to apply newly calculated electricity or due-date values.

## Meter Reading Management

- Added Edit and Delete controls on the main Meter Reading page.
- Editing validates chronological position and prevents readings from breaking the room meter sequence.
- Deleting or editing a reading recalculates the immediately following reading’s unit difference.

## Property Selection and Navigation

- When a PG is selected in the header switcher, the sidebar **Properties** item opens that PG’s profile instead of the all-properties list.
- Changing the header switcher now performs a full browser navigation after saving the selection. This guarantees every sidebar screen and property profile loads data for the newly selected PG on every switch; a property-profile URL also changes to the newly selected PG profile.
- The property profile has a working Edit form, and the all-properties table Edit action uses the same form.
- The profile shortcuts now open existing selected-property sidebar pages:
  - Overview → Dashboard
  - Rooms → Structure
  - Tenants → Tenants
  - Billing → Billing
  - Readings → Meter Reading
- The unused Payments shortcut was removed because Payments remains marked as upcoming in the sidebar.
- Removed the obsolete profile back arrow which returned to the all-properties list.

## Notes for Future Changes

- Billing calculations are controlled by `apps/api/src/lib/electricity.ts` and the bill-generation route, not by invoice display code.
- Do not alter already-issued bills automatically when readings change; invoices are financial snapshots. Delete and regenerate only when the owner explicitly needs a corrected invoice.
- The top property selector is the source of truth for dashboard sidebar pages that operate on a single PG.
