## Features Built

### 1. Manual Tenant Approval Workflow
**Commit:** `3ac3636`

**Problem:** Tenants created via public signup were auto-activated, bypassing owner review.

**Solution:** All tenant creation (manual and public) now creates `pending` status. Owner must approve from tenants list.

**Files Modified:**
- `apps/api/src/routes/tenants.ts` - Changed POST `/` to create pending tenants
- `apps/web/src/hooks/use-tenants.ts` - Added useApproveTenant, useRejectTenant
- `apps/web/src/app/(dashboard)/dashboard/tenants/page.tsx` - Added Approve/Reject buttons
- `apps/web/src/app/(dashboard)/dashboard/properties/[propertyId]/tenants/new/page.tsx` - Updated form to show "Add for approval"

**API Changes:**
- `POST /:tenantId/approve` - Approve and assign bed
- `POST /:tenantId/reject` - Reject tenant
- `POST /:tenantId/onboarding-link` - Generate onboarding token

---

### 2. Advance Payment UI
**Commit:** `6a303f0`

**Problem:** Backend had `useApplyAdvancePayment` hook but no UI to use it.

**Solution:** Added "Apply advance" button in expanded bill row with dialog to select advance and amount.

**Files Modified:**
- `apps/web/src/hooks/use-advance-payments.ts` - Added type for apply mutation
- `apps/web/src/app/(dashboard)/dashboard/properties/[propertyId]/billing/page.tsx` - Added dialog

**Features:**
- Select from available advances
- Defaults to min(advance available, bill balance)
- Validates amount doesn't exceed available

---

### 3. Invoice Voiding
**Commit:** `50eb204`

**Problem:** Owners make billing mistakes. Deleting bills destroys audit trail.

**Solution:** `POST /:billId/void` sets `voidedAt`, zeros balance, preserves record.

**Files Modified:**
- `apps/api/src/routes/billing.ts` - Added void endpoint
- `apps/api/src/lib/late-fee.ts` - Skips voided bills
- `apps/web/src/hooks/use-bills.ts` - Added useVoidBill
- `apps/web/src/app/(dashboard)/dashboard/properties/[propertyId]/billing/page.tsx` - Added Void button

**API:** `POST /v1/properties/:pid/bills/:billId/void`

---

### 4. Promised Payment Date
**Commit:** `50eb204`

**Problem:** Tenant says "I'll pay on the 15th." Owner needs to suspend late fees.

**Solution:** `PATCH /:billId/promised-date` suspends late fees until specified date.

**Files Modified:**
- `packages/db/src/schema.ts` - Added `promisedDate` column to `bill` table
- `apps/api/src/lib/late-fee.ts` - Added `promisedDate` parameter
- `apps/api/src/routes/billing.ts` - Added PATCH endpoint
- `packages/db/drizzle/0013_colossal_cassandra_nova.sql` - Migration
- `apps/web/src/hooks/use-bills.ts` - Added useSetPromisedDate
- `apps/web/src/types/index.ts` - Added `promisedDate` to Bill type

**API:** `PATCH /v1/properties/:pid/bills/:billId/promised-date`

### Cloudflare R2 Storage Integration
**Commit:** `34146e5`

**Free tier:** 10 GB storage, 1M Class A ops, 10M Class B ops, zero egress.

**Features:**
- Document upload (base64 → R2)
- Automatic URL generation
- Delete from R2 on document removal
- Fallback to direct URLs if R2 not configured

**Configuration:**
```env
R2_ACCOUNT_ID=your_account_id
R2_ACCESS_KEY_ID=your_access_key
R2_SECRET_ACCESS_KEY=your_secret_key
R2_BUCKET_NAME=pgkhata-documents
R2_PUBLIC_URL=https://pub-xxx.r2.dev
```
